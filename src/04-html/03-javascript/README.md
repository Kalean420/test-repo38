# JavaScript: zadanie kontrolne

Przycisk zmienia tekst `#fact-text`. Funkcja `addEventListener` uruchamia się po kliknięciu. `querySelector` zwraca `null`, gdy selektora brak; skrypt sprawdza oba elementy przed obsługą zdarzenia. Do ćwiczenia zmień selektor na błędny, sprawdź Console, przywróć go i sprawdź kliknięcie.
