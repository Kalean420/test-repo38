# HTML: zadanie kontrolne

`head` zawiera metadane i tytuł karty; `body` treść. `title` opisuje kartę, `h1` jest głównym nagłówkiem strony. Lista zainteresowań ma trzy pozycje. `header/nav` to nawigacja, `main` treść, `footer` stopka. Po eksperymencie z brakującym zamknięciem listy przywróć znacznik i sprawdź DOM w DevTools.
