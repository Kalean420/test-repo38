# Portfolio i GitHub Pages

Witryna zawiera trzy strony z nawigacją, dwa opisane projekty, wspólny responsywny CSS i interakcję JS. Lokalnie otwórz `Portfolio/index.html`, przejdź linkami, zmniejsz szerokość okna, kliknij przycisk i sprawdź Console. Do publikacji skopiuj zawartość `Portfolio/` do `docs/` w root repozytorium, w GitHub **Settings → Pages** wybierz `main` i `/docs`, po publikacji sprawdź podstrony i wąski ekran.
