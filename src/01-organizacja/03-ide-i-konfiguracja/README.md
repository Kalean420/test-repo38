# IDE, C# i .NET

`HelloWorkshop` wyświetla `Hello, Kalean420!`. Uruchom z katalogu głównego:

```text
dotnet --version
dotnet build src/01-organizacja/03-ide-i-konfiguracja/HelloWorkshop/HelloWorkshop.csproj
dotnet run --project src/01-organizacja/03-ide-i-konfiguracja/HelloWorkshop/HelloWorkshop.csproj
```

Otwórz projekt w VS Code, Visual Studio i Riderze. Ustaw breakpoint na `Console.WriteLine`, rozpocznij debugowanie i sprawdź zatrzymanie. Zapisz lokalnie wersję SDK oraz rezultat; zależą od narzędzi zainstalowanych na Twoim komputerze.
