# Laboratorium: IDE, Git i Pull Request

Projekt `IdeFunctionLab` liczy `f(x)=2x+3`; wyniki to `f(4)=11` i `f(-2)=-1`. Otwórz ten sam projekt w VS Code, Visual Studio i Riderze, zbuduj, uruchom, ustaw breakpoint w `Calculate` i przy wyświetlaniu wyniku, sprawdź `value`, a potem wznów. Zapisz własny rezultat i wersję SDK.

Własne repo: `git status`, `git add`, `git diff --staged`, `git commit`, `git push`. Utwórz `feature/readme-contact` i PR do `main`. Do ćwiczenia konfliktu zmień tę samą sekcję README na obu gałęziach, scal `main` do funkcjonalnej i rozwiąż konflikt, zachowując obie linie. Sprawdź diff, status i log. Nie dodawaj `bin/`, `obj/`, haseł ani tokenów.

Ćwiczenie w parze i rzeczywisty PR wymagają współpracownika oraz konta GitHub; konfigurację Pages opisano w `src/04-html/04-portfolio-github-pages/README.md`.
